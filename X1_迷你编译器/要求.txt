X1 迷你编译器 · 第一步：词法分析（tokenizer）
════════════════════════════════════════

目标：把一行算术表达式切成一个个 token。
      最终目标是做出"能算表达式"的迷你编译器，但一次只做一步。

文件：cpp学习\X1_迷你编译器\tokenizer.cpp
讲义：cpp学习\讲义\X1-1_词法分析.md


【要写的函数】

  #include <string>
  #include <vector>
  using namespace std;

  // 功能：把表达式字符串切成 token
  // 参数：s —— 例如 "12 + 3 * 4"
  // 返回：例如 {"12", "+", "3", "*", "4"}
  vector<string> fenci(string s);


【规则】

  ☐ 空格：跳过，不作为 token
  ☐ 数字：连续的数字（可以有一个小数点）合成一个 token
        "12" → 1 个；"3.5" → 1 个；"0.25" → 1 个
  ☐ 运算符：+ - * / ( )  每个都单独成一个 token
  ☐ 其他字符：打印 "非法字符: x" 并返回空 vector
  ☐ 空字符串：返回空 vector（不报错）


【main 要做什么】

  在 main 里写死这几组输入，逐组调用 fenci 并打印：

    "12 + 3 * 4"
    "(1.5+2)/3"
    "100"
    "   "              ← 只有空格
    "1+2*"
    "1a2"              ← 应该报非法字符

  每组打印格式随意，但要能一眼看出：输入是什么、有几个 token、分别是什么。

  例：
    [输入] 12 + 3 * 4
    [token 数] 5
    [token] 12 | + | 3 | * | 4


【提示】

  · string 取字符：s[i]，长度 (int)s.size()
  · 判断数字：c >= '0' && c <= '9'
  · 判断小数点：c == '.'
  · 攒字符串：string num = ""; num += c;
  · 存结果：vector<string> toks;  toks.push_back(x);
  · 外层 while 扫 + 内层 while 攒数字，是最容易写对的结构
  · ★ 数字循环里 i++ 的位置最容易错：
        当 s[i] 是数字时 → 攒进 num → i++ → 继续看下一个
        循环结束后不要再额外 i++（因为已经指向下一个非数字字符）


【验收标准】

  [ ] 编译零警告
  [ ] "12 + 3 * 4"      → 5 个：12 / + / 3 / * / 4
  [ ] "(1.5+2)/3"       → 7 个：( / 1.5 / + / 2 / ) / / / 3
  [ ] "100"             → 1 个：100
  [ ] "   "（三空格）    → 0 个
  [ ] "1+2*"            → 4 个：1 / + / 2 / *
  [ ] "1a2"             → 打印非法字符，返回 0 个

  ★ 用 build.bat / .\build.ps1 tokenizer 编译运行
