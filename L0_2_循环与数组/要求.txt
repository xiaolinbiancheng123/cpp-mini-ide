L0-2 任务：成绩统计（vector 版）
════════════════════════════════════════

文件放在这个文件夹里，命名 l0_2_score.cpp

★ 本文用 vector，不用内置数组 —— 结论：不考试的话 vector 全面优于数组。


【要做什么】

  输入若干个学生的「姓名 成绩」，输出总分、平均分、最高分、最低分，
  以及每个人的明细。


【头文件】

  #include <iostream>
  #include <vector>
  #include <string>


【输入方式】

  一直读到没有为止，不要先问「有几个人」：

      string name; int score;
      while (cin >> name >> score) {
          // 存起来
      }

  ★ 为什么不先问人数：
    1. 以后从文件读，文件里本来就有全部数据，多问一步是多余
    2. ifstream 和 cin 用法完全一样，切换只要改一行


【数据结构】

  两个平行 vector：

      vector<string> names;
      vector<int>    scores;

  存的时候两个一起 push_back，保证 names[i] 对应 scores[i]。

  ★ 顺序绝对不能错位 —— 一旦漏 push 一个，后面全部错位。
    这也是为什么以后要用 struct 把它们绑在一起（L0-3）。


【要求】

  1. 用一个 for 循环同时算：总分、最高、最低、平均
  2. 最高/最低的初始值要用「第一个元素」（打擂台），不能用 0
  3. 平均分带小数： total / (double)scores.size()
  4. 输出格式：

        明细:
          小林 88
          老王 76
          ...
        人数: 3
        总分: 259
        平均: 86.3333
        最高: 95
        最低: 76

  5. 如果一条输入都没有，要输出「没有输入数据」而不是崩掉或除以 0


【自己验证】

  用这组数据测：

      小林 88
      老王 76
      小张 95

  总分 259，平均 86.3333，最高 95，最低 76


【自查清单】

  [ ] 用了 vector，没有用 int a[n] 这种变长数组
  [ ] names 和 scores 的 push_back 次数一致（错位就全错）
  [ ] 最高/最低初始值取自第 0 个元素
  [ ] scores 为空时不会除以 0
  [ ] 循环里用 i < scores.size()，不是 <=
  [ ] 编译零警告
