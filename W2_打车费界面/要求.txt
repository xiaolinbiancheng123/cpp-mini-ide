════════════════════════════════════════

文件：cpp学习\W2_打车费界面\w2_taxi_gui.cpp
分两阶段：阶段 A 只做界面，阶段 B 才接计算。


【阶段 A：把界面摆出来，点按钮暂时没反应】

窗口：600 x 400，标题自拟（如 L"打车费计算器"）

  控件布局（客户区坐标，单位像素）：

  ┌──────────────────────────────────────────┐
  │                                          │
  │  公里数   [______________]               │  y=40
  │                                          │
  │  等待     [______________] 分钟          │  y=90
  │                                          │
  │           [   计算   ]                   │  y=140
  │                                          │
  │  总价: ——                                │  y=210
  │                                          │
  └──────────────────────────────────────────┘

  建议坐标（可以自己微调，但要整齐）：

    控件                类型       x    y    宽   高    内容
    ─────────────────────────────────────────────────────────
    "公里数"            STATIC     40   40   80   25     L"公里数"
    公里数输入框        EDIT      130   38  150   26     L""（空）
    "等待(分钟)"        STATIC     40   90  100   25     L"等待(分钟)"
    等待输入框          EDIT      150   88  150   26     L""（空）
    "计算"按钮          BUTTON    130  140  100   34     L"计算"
    总价显示            STATIC     40  210  400   30     L"总价: ——"


【必须用到的语法】

  1. 控件 ID：
         #define ID_KM      101
         #define ID_WAIT    102
         #define ID_BTN     103
         #define ID_RESULT  104
     ★ #define 后面不加分号，写在 #include 之后、所有函数之前

  2. 全局控件句柄（写在函数外面，WndProc 和 main 都能用）：
         HWND g_editKm   = nullptr;
         HWND g_editWait = nullptr;
         HWND g_btnCalc  = nullptr;
         HWND g_result   = nullptr;

  3. case WM_CREATE：在这里创建全部 6 个控件
         ★ 创建完 return 0;  —— 返回 -1 会让窗口创建直接失败

     创建语法参考（以第一个 EDIT 为例）：
         g_editKm = CreateWindowExW(
             0,
             L"EDIT",                      // 控件类名
             L"",                          // 初始文字
             WS_CHILD | WS_VISIBLE | WS_BORDER,
             130, 38, 150, 26,             // x, y, 宽, 高
             hwnd,                         // 父窗口（WM_CREATE 的 hwnd 就是主窗口）
             (HMENU)ID_KM,                 // 控件 ID
             GetModuleHandleW(nullptr),    // 程序实例
             nullptr);
         ★ 其余 5 个照着写，只改类名/文字/坐标/ID

  4. case WM_COMMAND：先留个空壳
         case WM_COMMAND:
             return 0;      // 阶段 A 什么都不做
