L0-1 任务：打车费计算器
════════════════════════════════════════

文件放在这个文件夹里，命名 l0_1_taxi.cpp


【计价规则】

  起步价      : 10 元（含 3 公里）
  超过 3 公里的部分 : 每公里 2.3 元
  低速等待     : 每分钟 0.3 元（按整数分钟算）


【输入】

  行驶公里数（小数，用 double 存）
  等待分钟数（整数，用 int 存）


【输出】

  起步价、里程费、等待费、总价，各一行


【示例】

  输入: 5.5 公里, 8 分钟

  起步价: 10 元
  里程费: 5.75 元          <- (5.5 - 3) × 2.3
  等待费: 2.4 元           <- 8 × 0.3
  总价:   18.15 元


【要求】

  1. 公里数和价格用 double，分钟用 int
  2. 先把「超过 3 公里」的部分算出来：(公里数 - 3) × 2.3
  3. 这一版先不用判断，假设顾客都开超过 3 公里
     —— 不到 3 公里会算出负数的漏洞，留到 L0-2 用 if 补


【怎么编译运行】

  在 VS Code 里打开 l0_1_taxi.cpp，按 Ctrl+Shift+B
  选「编译并运行（当前文件）」

  或者在终端里：
    cd 本文件夹
    g++ -std=c++11 -o l0_1_taxi.exe l0_1_taxi.cpp
    .\l0_1_taxi.exe


【提示（不含答案）】

  · 里程费 = (公里数 - 3) * 2.3       注意括号
  · 等待费 = 分钟数 * 0.3             注意 0.3 是小数，结果才是小数
  · 总价   = 起步价 + 里程费 + 等待费
  · 输出时想保留两位小数？本节还没讲，先用默认的，数字对就行
