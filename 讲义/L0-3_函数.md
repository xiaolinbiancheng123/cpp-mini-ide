## 一、函数能干什么

**你现在遇到的问题：三个输入框要做"三遍一模一样的校验"。**

```
读公里数 → 判空 → 解析 → 判 NaN → 跳空格 → 判格式 → 判范围
读等待   → 判空 → 解析 → 判 NaN → 跳空格 → 判格式 → 判范围   ← 复制一遍
读单价   → 判空 → 解析 → 判 NaN → 跳空格 → 判格式 → 判范围   ← 再复制一遍
```

**★ 函数就是把这一串打包：**

```cpp
double 公里数;
if (!读数字(g_editKm, L"公里数", 0, 1000, 公里数)) return 0;
if (!读数字(g_editWait, L"等待", 0, 1000, 等待))      return 0;
if (!读数字(g_editGongli, L"单价", 1, 1000, 单价))    return 0;
```

**★★ 改一处校验规则，三个输入框一起生效——这就是函数的全部价值。**

## 二、语法点

### ① 最简单的函数：无参数、无返回值

```cpp
void sayHi()
{
    std::cout << "hi" << std::endl;
}

int main()
{
    sayHi();      // 调用：函数名 + ()
    return 0;
}
```

| 部分 | 含义 |
|---|---|
| `void` | **返回值类型**——`void` = 什么都不返回 |
| `sayHi` | 函数名（你自己起） |
| `()` | 参数列表，空的表示不要参数 |
| `{ ... }` | 函数体，真正执行的代码 |
| `sayHi();` | **调用**：跑到这行就跳进函数体，执行完再回来 |

---

### ② 带参数、带返回值

```cpp
double jisuanlichengfei(double km, double danjia)
{
    if (km <= 3.0) {
        return 0.0;              // return 把值交回给调用者
    }
    return (km - 3.0) * danjia;
}

int main()
{
    double fei = jisuanlichengfei(5.5, 2.3);   // 调用，返回值存进 fei
    // fei = 5.75
}
```

| 关键点 | 说明 |
|---|---|
| **参数** | 括号里声明"我要什么"：`double km, double danjia` |
| **调用时传值** | `jisuanlichengfei(5.5, 2.3)` → km 收到 5.5，danjia 收到 2.3 |
| **`return 值;`** | 立刻结束函数，把值交给调用者 |
| **返回值类型** | 必须和 `return` 的值类型一致（这里是 double） |

**★ 一个函数遇到 `return` 就立刻结束，后面的代码不再执行。**

---

### ③ 引用参数：让函数修改外面的变量

**普通参数是"复制一份进去"：**

```cpp
void xiugai(double x)
{
    x = 100;        // 改的是副本，外面的变量不变
}
```

**引用参数（`&`）是"直接改原来那个"：**

```cpp
void xiugai(double& x)
{
    x = 100;        // 改的就是外面那个变量
}

int main()
{
    double a = 5;
    xiugai(a);
    // a 现在是 100
}
```

**★ `double& x` 的意思是"x 是外面某个 double 的**别名**"——不是复制，是同一个东西。**

**★★ 这就是"**输出参数**"的写法：函数要返回多个值的时候用。**

```cpp
bool 读数字(HWND 框, ..., double& 结果)
//                     ↑ 结果从这里"流"出去
```

---

### ④ 局部变量与作用域

```cpp
void f()
{
    int x = 1;      // x 只活在 f 里面
}

int main()
{
    int x = 2;      // 这是另一个 x
    f();
    // 这里的 x 还是 2
}
```

**★ 函数里面定义的变量，函数外面**看不见**。这叫**作用域**。**
**★★ 反过来也成立：函数只能看到自己的局部变量 + 全局变量（比如你的 `g_editKm`、`g_result`）。**

---

### ⑤ 先声明，后使用

**如果函数写在调用它的代码**后面**，编译器不认识它。两种解法：**

```cpp
// 解法一：把函数定义放在调用之前（最简单）

// 解法二：先写"函数原型"声明
bool 读数字(HWND 框, const wchar_t* 名字, double 最小, double 最大, double& 结果);
// ↑ 只有签名，没有函数体，最后带分号

int main() { ... }        // 现在可以调用
bool 读数字(...) { ... }  // 函数体写在后面
```

**★ 编译器是"从上往下"扫的——它得先知道有这个函数，才允许你调用。**

---

### ⑥ 其实你一直在用函数

```
main()        ← 程序的入口函数
GetWindowTextW(...)   ← Windows 提供的函数
wcstod(...)           ← C 库函数
SetWindowTextW(...)   ← 又一个
```

**★ 函数不是新东西，只是以前是**别人写好的**，现在你要**自己写**。**

## 三、拼装示例

**完整的三个例子（可以直接编译跑）：**

```cpp
#include <iostream>
#include <cwchar>
using namespace std;

// ① 无参数无返回值
void sayHi()
{
    cout << "hi" << endl;
}

// ② 带参数带返回值
double jisuanlichengfei(double km, double danjia)
{
    if (km <= 3.0) {
        return 0.0;
    }
    return (km - 3.0) * danjia;
}

// ③ 带引用参数（输出参数）
bool jiancha(double zhi, double zuiXiao, double zuiDa, double& jieguo)
{
    if (zhi < zuiXiao || zhi > zuiDa) {
        return false;      // 不在范围内
    }
    jieguo = zhi;          // 通过引用写出去
    return true;
}

int main()
{
    sayHi();

    double fei = jisuanlichengfei(5.5, 2.3);
    cout << "里程费: " << fei << endl;         // 5.75

    double x = 0;
    if (jiancha(8.0, 0.0, 10.0, x)) {
        cout << "通过: " << x << endl;          // 8
    } else {
        cout << "超出范围" << endl;
    }
    return 0;
}
```

## 四、本课任务

### 任务 A（简单）：把计算拆成函数

```
☐ 写 double jisuanlichengfei(double km, double danjia)
     —— 3 公里内返回 0，超出部分 × 单价
☐ 写 double jisuandengdaifei(double fenzhong)
     —— 分钟 × 0.3
☐ 在 WM_COMMAND 里调用它们
```

### 任务 B（核心）：写一个读数字函数

```cpp
bool duShuzi(HWND kuang, const wchar_t* mingzi, double zuiXiao, double zuiDa, double& jieguo)
```

**它要做完你现在那六步校验，全对才返回 true：**

```
① 读输入框文字
② 空 → 提示"请输入XXX"，返回 false
③ wcstod 解析
④ NaN（值不等于自己）→ 提示"XXX 请输入有效数字"，返回 false
⑤ 跳过尾部空格
⑥ *end 不是 '\0' → 提示"XXX 请输入有效数字"，返回 false
⑦ 小于 zuiXiao 或大于 zuiDa → 提示"XXX 超出范围"，返回 false
⑧ 全通过 → jieguo = 值，返回 true
```

**提示：**
- `mingzi` 参数用来拼错误信息：`swprintf(提示, 64, L"%ls 请输入有效数字", mingzi)`
- 宽度格式符 `%ls` 用于宽字符串（在 `swprintf` 里）
- 全局 `g_result` 在函数里可以直接用

### 任务 C：重构 WM_COMMAND

```
☐ 三个输入 → 三次 duShuzi 调用
☐ 任意一个失败 → return 0（函数里已经显示了错误信息）
☐ 全通过 → 计算 → 显示总价
```

## 六、本课结论

```
① 函数 = 给一段代码起名字，重复用
② 返回值类型 + 函数名 + 参数列表 + 函数体
③ void 表示不返回；return 立刻结束函数
④ 普通参数是复制；& 引用参数能改外面的变量（输出参数）
⑤ 局部变量只活在函数里
⑥ 函数必须先声明/定义再调用
⑦ 函数的意义：改一处，处处生效
```
