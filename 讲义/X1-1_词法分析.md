# X1 讲义（一）：写个编译器 —— 第一步「词法分析」

> **目标**：写一个函数，把一行算术表达式切成一个个"词"（token）。
> 例：`"12 + 3 * 4"` → `["12", "+", "3", "*", "4"]`
>
> **这是我们迷你编译器的第一步。**最终目标是能算出表达式结果。
> 但先别急——**好的编译器作者都是先把词法分析写干净，再写下一步。**

---

## 一、编译器整体长什么样

```
源代码字符串
   │
   ▼ ① 词法分析（Tokenizer/Lexer）        ← 今天只做这一步
[ "12", "+", "3", "*", "4" ]
   │
   ▼ ② 语法分析（Parser）                  ← 下一课
   语法树
   │
   ▼ ③ 求值 / 生成代码（Evaluator/CodeGen） ← 再下一课
   结果（或源代码）
```

**★ 分三步写的原因：每一步都能单独测试。**如果一次性写完 200 行，出错了你不知道是哪个阶段坏的。**

---

## 二、什么是 token（词法单元）

**编译器不认识"字符串"，它只认识一个个有意义的单元。**

| 输入 | token 序列 |
|---|---|
| `12 + 3 * 4` | `12`、`+`、`3`、`*`、`4` |
| `(1.5 + 2) / 3` | `(`、`1.5`、`+`、`2`、`)`、`/`、`3` |

**★ 规则很简单：**

```
数字（含小数点）      → 一个 token（可以是多位数、小数）
+ - * / ( )          → 各是一个 token
空格                 → 跳过，不作为 token
其他字符             → 报错（非法字符）
```

**★★ 关键：`123` 必须被识别成**一个** token，不是 `1`、`2`、`3` 三个——所以数字要"连续读取"。**

## 三、本节需要的语法（都是你学过或马上要用的）

### ① `std::string` 和下标

```cpp
#include <string>
using namespace std;

string s = "abc";
cout << s[0];        // 'a'
cout << s.size();    // 3
```

**★ `s[i]` 取第 i 个字符（类型 `char`），下标从 0 开始，最后一个是 `s.size()-1`。**

### ② 判断字符是数字 / 小数点

```cpp
char c = s[i];
if (c >= '0' && c <= '9') { ... }      // 是数字
if (c == '.') { ... }                  // 小数点
if (c == ' ') { ... }                  // 空格
```

**★ 用 `'0'`、`'9'` 这种**字符字面量**直接比较——因为字符本质是小整数（'0' = 48，'9' = 57），连续排列。**

### ③ `vector<string>`：存一堆 token

```cpp
#include <vector>
vector<string> tokens;                 // 空的可变长数组
tokens.push_back("12");                // 末尾添加
tokens.push_back("+");
cout << tokens.size();                 // 2
cout << tokens[0];                     // 12
```

**★ `vector` 就是个会自动变长的数组——你 L0-2 学过。**

### ④ 字符串拼接

```cpp
string num = "";
num += '1';        // 加一个字符
num += '2';        // "12"
```

**★ `+=` 可以往字符串末尾追加字符，用来"攒数字"。**

### ⑤ 遍历字符串（三种写法，选一种你熟的）

```cpp
// 写法一：下标循环（推荐，因为要"看下一个字符"）
for (int i = 0; i < (int)s.size(); i++) {
    char c = s[i];
}

// 写法二：范围 for（C++11）
for (char c : s) { ... }
```

**★ 词法分析必须用**写法一**——因为识别数字时要往后多看几位，得自己控制 `i`。**

## 四、词法分析的算法（伪代码，看懂了再写）

```
从头到尾扫每个字符 i：

  如果 s[i] 是空格：
      i 往后移一位，继续

  否则如果 s[i] 是数字 或 小数点：
      创建空字符串 num
      当 i 还在范围内 且 s[i] 是数字或小数点：
          num += s[i]
          i 往后移
      tokens.push_back(num)        ← 连续的数字攒成一个 token
      （注意：此时不要再 i++，因为循环条件会继续）

  否则如果 s[i] 是 + - * / ( ) 之一：
      tokens.push_back( 一个字符组成的字符串 )
      i 往后移

  否则：
      报错："非法字符"
```

**★ 最容易写错的地方：数字循环里 `i` 怎么移动。**想清楚"什么时候加 i、什么时候不加"。**

## 五、拼装示例（不同任务，但结构一样）

**这只是示范"扫描 + 攒字符串 + 存进 vector"的骨架，不是你的作业：**

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// 功能：把字符串里所有的"字母串"抽出来
vector<string> chouzimu(string s)
{
    vector<string> jieguo;
    int i = 0;
    while (i < (int)s.size())
    {
        char c = s[i];
        if (c >= 'a' && c <= 'z')
        {
            string ci = "";
            while (i < (int)s.size() && s[i] >= 'a' && s[i] <= 'z')
            {
                ci += s[i];
                i++;
            }
            jieguo.push_back(ci);
        }
        else
        {
            i++;               // 不是字母就跳过
        }
    }
    return jieguo;
}

int main()
{
    vector<string> r = chouzimu("ab12cd3");
    for (int i = 0; i < (int)r.size(); i++) {
        cout << r[i] << endl;   // ab / cd
    }
    return 0;
}
```

**★ 结构跟你作业完全一样：外层 while 扫，内层 while 攒，攒完 push_back。**
**★★ 区别只是：你的作业要识别**数字**和**运算符**，还要处理空格。**

## 七、验收标准（我出数据，你来跑）

| 输入 | 期望输出 |
|---|---|
| `12 + 3 * 4` | `12` / `+` / `3` / `*` / `4`（5 个） |
| `(1.5+2)/3` | `(` / `1.5` / `+` / `2` / `)` / `/` / `3`（7 个） |
| `100` | `100`（1 个） |
| `  `（只有空格） | 0 个 |
| `1+2*` | `1` / `+` / `2` / `*`（4 个） |
| `1a2` | 报"非法字符" |

**★ 全部通过，第一步就算完成。**下一课我们用这些 token 搭"语法树"并算出结果。**

## 八、常见坑（先打预防针）

| 坑 | 症状 |
|---|---|
| **数字循环里忘了 `i++`** | 死循环，程序卡住 |
| **数字循环里多加了 `i++`** | `12` 变成 `1`、`2` 两个 token |
| **忘了处理空输入** | `s.size()==0` 时直接跑没问题，但别去 `s[0]` |
| **用了 `s.length()` 和 `(int)` 混用** | 会有警告；统一 `(int)s.size()` |
| **小数点点两次** | `1.2.3` 会被攒成一个 token——先不处理，验收不考这个 |
