## `for` 循环

```cpp
for (int i = 0; i < 5; i++) {
    cout << i << endl;
}
```

| 部分 | 作用 | 执行时机 |
|---|---|---|
| `int i = 0` | 起点 | **仅一次** |
| `i < 5` | 继续条件 | 每轮开始前 |
| `i++` | 每轮之后 | 每轮结束 |

**执行顺序：初始化 → 判断 → 循环体 → `i++` → 判断 → 循环体 → …… → 判断失败退出**

### 边界陷阱

```cpp
for (int i = 0; i <= 5; i++)   // ❌ 跑 6 次
for (int i = 0; i < 5; i++)    // ✅ 跑 5 次
```

### 第三段可以任意写

```cpp
for (int i = 0; i < 10; i += 2)   // 0 2 4 6 8
for (int i = 5; i > 0; i--)       // 5 4 3 2 1
```

### `continue` 不会跳过 `i++`

```cpp
for (int i = 0; i < 5; i++) {
    if (i == 2) continue;    // 跳过本轮剩下的，但 i++ 照常执行
    cout << i;               // 输出 0134
}
```

## `while` 循环

```cpp
int n = 0;
while (n < 5) {
    cout << n << endl;
    n++;                    // ★ 忘了这句就是死循环
}
```

| 用哪个 | 场景 |
|---|---|
| `for` | **知道循环几次**（遍历数组） |
| `while` | **只知道停止条件**（读到文件尾、输入 0 退出） |

---

## `break` / `continue`

```cpp
break;      // 立刻跳出整个循环
continue;   // 跳过本轮剩下的，进入下一轮
```

## 数组

```cpp
const int N = 5;
int scores[N] = {88, 76, 95, 61, 82};   // 声明时给初值
int zeros[N]  = {0};                    // 全部清零

scores[0]   // 第 1 个：88
scores[4]   // 第 5 个（最后一个）：82
scores[5]   // ❌ 越界
```

**下标范围永远是 `0` 到 `N-1`。**

### 三个必须知道的坑

**① 越界不报错**

```cpp
int a[5];
a[5]  = 100;    // ❌ 编译器可能不报错，直接破坏别的内存
```

C/C++ 默认相信你不会写错，不帮你检查越界。表现为「莫名崩溃」或「结果对不上」。

**② 长度别手算**

```cpp
for (int i = 0; i < 5; i++)   // ❌ 改成 6 个学生时会忘
for (int i = 0; i < N; i++)   // ✅ 跟着 N 走
```

**③ 数组不能整体赋值**

```cpp
int a[5] = {1,2,3,4,5};
int b[5];
b = a;          // ❌ 编译错误
```

## 两个经典算法套路

### 累加

```cpp
int total = 0;
for (int i = 0; i < N; i++) {
    total += scores[i];
}
```

### 打擂台（求最大/最小）

```cpp
int max = scores[0];            // ★ 用第一个当擂主，不要用 0
for (int i = 1; i < N; i++) {
    if (scores[i] > max) max = scores[i];
}
```

**为什么不用 `max = 0`？如果所有数都是负数，0 永远比它们大，`max` 就更新不了，最后输出一个根本不存在于数组里的 0。**

---

## 一个循环干多件事

```cpp
int total = 0, max = scores[0], min = scores[0];
for (int i = 0; i < N; i++) {
    total += scores[i];
    if (scores[i] > max) max = scores[i];
    if (scores[i] < min) min = scores[i];
}
double avg = total / (double)N;     // 别忘 (double)，否则整数除法砍小数
```

**这就是 L0-2 任务的标准解法。**

## 变量职责提醒

```cpp
int a = 0;                       // ❌ a 只是跟着 i 走，多余
for (int i = 0; i < 6; i++) { a = a + 1; cout << a; }

for (int i = 1; i <= 6; i++) {   // ✅ 起点直接设 1
    cout << i;
}
```

**判断标准：这个变量在循环结束后还有用吗？只做中转就别开它。**
