# 控件速查：各类型怎么创建

> 所有控件都是"子窗口"，创建方式完全一样：
> `CreateWindowExW(0, 类名, 初始文字, 样式, x, y, 宽, 高, 父窗口, (HMENU)ID, hInst, nullptr)`
> 区别只在**类名**、**样式**、**要不要额外初始化**、**用什么消息操作**。

---

## 一、六种基础控件（系统内置，不用额外初始化）

| 控件 | 类名 | 关键样式 | 用途 |
|---|---|---|---|
| **静态文本/图片** | `L"STATIC"` | `SS_CENTER` 居中、`SS_ICON` 图标、`SS_ETCHEDFRAME` 分隔线 | 标签、说明文字 |
| **单行输入框** | `L"EDIT"` | `ES_NUMBER` 只许数字、`ES_PASSWORD` 密码点、`ES_AUTOHSCROLL` | 输入 |
| **多行文本框** | `L"EDIT"` | `ES_MULTILINE \| WS_VSCROLL \| ES_AUTOVSCROLL` | 日志、记事 |
| **按钮** | `L"BUTTON"` | `BS_DEFPUSHBUTTON` 默认按钮、`BS_CHECKBOX` 复选、`BS_RADIOBUTTON` 单选 | 点击 |
| **下拉框** | `L"COMBOBOX"` | `CBS_DROPDOWNLIST` 只选不能改、`CBS_DROPDOWN` 可输入 | 选择 |
| **列表框** | `L"LISTBOX"` | `LBS_NOTIFY` 选中时通知父窗口、`WS_VSCROLL` | 列表 |
| **滚动条** | `L"SCROLLBAR"` | `SBS_HORZ` / `SBS_VERT` | 手动滚动 |

### 创建示例（一次造齐）

```cpp
// 标签
CreateWindowExW(0, L"STATIC", L"公里数",
    WS_CHILD | WS_VISIBLE,
    40, 40, 80, 25,
    hwnd, nullptr, GetModuleHandleW(nullptr), nullptr);

// 输入框
g_edit = CreateWindowExW(0, L"EDIT", L"",
    WS_CHILD | WS_VISIBLE | WS_BORDER | ES_AUTOHSCROLL,
    130, 38, 150, 26,
    hwnd, (HMENU)ID_EDIT, GetModuleHandleW(nullptr), nullptr);

// 多行文本框
g_log = CreateWindowExW(0, L"EDIT", L"",
    WS_CHILD | WS_VISIBLE | WS_BORDER | WS_VSCROLL
        | ES_MULTILINE | ES_AUTOVSCROLL | ES_READONLY,
    40, 200, 400, 150,
    hwnd, (HMENU)ID_LOG, GetModuleHandleW(nullptr), nullptr);

// 按钮
g_btn = CreateWindowExW(0, L"BUTTON", L"计算",
    WS_CHILD | WS_VISIBLE | BS_DEFPUSHBUTTON,
    130, 140, 100, 34,
    hwnd, (HMENU)ID_BTN, GetModuleHandleW(nullptr), nullptr);

// 复选框
g_chk = CreateWindowExW(0, L"BUTTON", L"记住密码",
    WS_CHILD | WS_VISIBLE | BS_CHECKBOX,
    40, 180, 120, 24,
    hwnd, (HMENU)ID_CHK, GetModuleHandleW(nullptr), nullptr);

// 下拉框（第三个参数是初始选中项文字）
g_combo = CreateWindowExW(0, L"COMBOBOX", L"",
    WS_CHILD | WS_VISIBLE | CBS_DROPDOWNLIST | WS_VSCROLL,
    130, 220, 150, 200,      // ★ 高度是"下拉展开时的高度"，不是收起高度
    hwnd, (HMENU)ID_COMBO, GetModuleHandleW(nullptr), nullptr);
```

## 二、通用控件（Common Controls）——需要额外三步

**这些控件在 `comctl32.dll` 里，不在基础 user32 里：**

| 控件 | 类名 | 用途 |
|---|---|---|
| **进度条** | `L"msctls_progress32"` | 下载/任务进度 |
| **滑块** | `L"msctls_trackbar32"` | 音量、亮度 |
| **上下微调（数字框）** | `L"msctls_updown32"` | 配合 EDIT 用 |
| **列表视图（表格）** | `L"SysListView32"` | 文件列表、表格数据 |
| **树形视图** | `L"SysTreeView32"` | 目录树、分类 |
| **标签页** | `L"SysTabControl32"` | 多页切换 |
| **状态栏** | `L"msctls_statusbar32"` | 底部状态栏 |
| **日期选择** | `L"SysDateTimePick32"` | 选日期 |
| **月历** | `L"SysMonthCal32"` | 选日期（展开式） |
| **工具栏** | `L"ToolbarWindow32"` | 图标按钮条 |

### 三步准备

**① 头文件**

```cpp
#include <commctrl.h>
```

**② 链接库（编译命令加 `-lcomctl32`）**

```powershell
g++ -std=c++11 -Wall -o out.exe main.cpp -lgdi32 -luser32 -lcomctl32
```

**③ 程序启动时初始化（main 一开头）**

```cpp
INITCOMMONCONTROLSEX icc;
icc.dwSize = sizeof(icc);
icc.dwICC  = ICC_WIN95_CLASSES | ICC_STANDARD_CLASSES;
InitCommonControlsEx(&icc);
```

**★ 不做第 ③ 步：`CreateWindowExW` 返回空，控件造不出来，也不报错。**

### 创建示例

```cpp
// 进度条
g_progress = CreateWindowExW(0, L"msctls_progress32", L"",
    WS_CHILD | WS_VISIBLE,
    40, 300, 300, 24,
    hwnd, (HMENU)ID_PROGRESS, GetModuleHandleW(nullptr), nullptr);

// 设置进度（0~100）
SendMessageW(g_progress, PBM_SETPOS, 50, 0);

// 滑块
g_slider = CreateWindowExW(0, L"msctls_trackbar32", L"",
    WS_CHILD | WS_VISIBLE | TBS_HORZ | TBS_AUTOTICKS,
    40, 340, 300, 30,
    hwnd, (HMENU)ID_SLIDER, GetModuleHandleW(nullptr), nullptr);

// 设置范围 0~100，当前值 50
SendMessageW(g_slider, TBM_SETRANGE, TRUE, MAKELPARAM(0, 100));
SendMessageW(g_slider, TBM_SETPOS, TRUE, 50);
```

## 三、怎么操作它们（按控件查消息）

**基础控件大多用 `GetWindowTextW` / `SetWindowTextW` / `SendMessageW`：**

| 操作 | 用什么 |
|---|---|
| 读/写文字 | `GetWindowTextW` / `SetWindowTextW` |
| 按钮点击 | 父窗口收 `WM_COMMAND`，`LOWORD(wParam)` = 控件 ID |
| 复选框是否勾选 | `SendMessageW(hChk, BM_GETCHECK, 0, 0)` → `BST_CHECKED` |
| 手动设置勾选 | `SendMessageW(hChk, BM_SETCHECK, BST_CHECKED, 0)` |
| 下拉框加一项 | `SendMessageW(hCombo, CB_ADDSTRING, 0, (LPARAM)L"第一项")` |
| 下拉框取选中项 | `SendMessageW(hCombo, CB_GETCURSEL, 0, 0)` → 下标 |
| 下拉框取选中文字 | `SendMessageW(hCombo, CB_GETLBTEXT, 下标, (LPARAM)buf)` |
| 列表框加项 | `SendMessageW(hList, LB_ADDSTRING, 0, (LPARAM)L"项")` |
| 表格加行（ListView） | `SendMessageW(hList, LVM_...)`（复杂，需要先 `LVM_INSERTCOLUMN`） |
| 进度条设值 | `SendMessageW(hProgress, PBM_SETPOS, 百分比, 0)` |
| 加/删文字（多行框） | `SendMessageW(hEdit, EM_REPLACESEL, ...)` 或 `SetWindowTextW` 追加 |
| 让控件获得焦点 | `SetFocus(hwnd)` |
| 启用/禁用 | `EnableWindow(hwnd, FALSE/TRUE)` |
| 显示/隐藏 | `ShowWindow(hwnd, SW_SHOW/SW_HIDE)` |
| 移动/改大小 | `MoveWindow(hwnd, x, y, w, h, TRUE)` |

## 四、选型速查：我要做 X，该用哪个控件

| 需求 | 用 |
|---|---|
| 显示一行提示 | `STATIC` |
| 输入数字/文字 | `EDIT` |
| 密码 | `EDIT` + `ES_PASSWORD` |
| 多行日志 | `EDIT` + `ES_MULTILINE \| WS_VSCROLL` |
| 点一下执行某功能 | `BUTTON` + `BS_DEFPUSHBUTTON` |
| 开/关选项 | `BUTTON` + `BS_CHECKBOX` |
| 多选一（少量） | `BUTTON` + `BS_RADIOBUTTON`（同一组要连续创建） |
| 多选一（较多） | `COMBOBOX` + `CBS_DROPDOWNLIST` |
| 一组数据 | `LISTBOX` 或 `SysListView32`（表格） |
| 进度 | `msctls_progress32` |
| 调数值 | `msctls_trackbar32` 或 `EDIT` + `msctls_updown32` |
| 分页 | `SysTabControl32` |
| 树形目录 | `SysTreeView32` |

## 五、你现在该学几个

**★ 现在只需要前三种：`STATIC`、`EDIT`、`BUTTON`——W2 打车费全用它们，够做 90% 的小工具。**

**★★ `SysListView32`（表格）、`COMBOBOX`（下拉）、`msctls_progress32`（进度条）是下一个项目会用到的，等需要时再学。**

**★★★ 一句话：所有控件都是 `CreateWindowExW` 一个函数造出来的，差别只有**类名**和**样式**——不用背，用的时候查这张表。**
