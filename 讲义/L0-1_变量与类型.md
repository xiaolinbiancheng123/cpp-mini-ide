# L0-1 讲义：变量、类型、运算、输入输出

> 目标：看懂一个命令行程序的骨架，会存数据、会算、会读写。

## 本节头文件

| 头文件 | 提供什么 | 用到的东西 |
|---|---|---|
| `<iostream>` | 控制台输入输出 | `cout`、`cin`、`endl` |
| `<string>` | 字符串类型 | `string` |

`using namespace std;` 的作用是省掉每处 `std::` 前缀。

---

## 类型一览

| 类型 | 装什么 | 字面量写法 | 占用 |
|---|---|---|---|
| `int` | 整数 | `42`、`-7` | 4 字节 |
| `double` | 小数 | `3.14` | 8 字节 |
| `char` | 单个字符 | `'A'`（**单引号**） | 1 字节 |
| `bool` | 真/假 | `true` / `false` | 1 字节 |
| `string` | 一串字符 | `"你好"`（**双引号**） | 可变 |

**单引号是字符，双引号是字符串，不能混用。**

### 命名规则

- 可用：字母、数字、下划线（不能数字开头）
- 不可用：空格、连字符、C++ 关键字
- 区分大小写：`Age` ≠ `age`

### 声明 / 赋值 / 初始化

```cpp
int a;          // 声明，值是垃圾（危险）
a = 10;         // 赋值
int b = 10;     // 初始化（推荐，永远用这个）
```

## 运算符

```cpp
a + b   a - b   a * b   a / b   a % b     // % 是取余
a += 5  a -= 5  a *= 2  a++  a--           // 简写
a == b  a != b  a > b  a <= b              // 比较，结果是 bool
```

### ★ 整数除法陷阱

```cpp
int x = 7, y = 2;
double r1 = x / y;          // 3    ← 先算整数除法，再转 double
double r2 = (double)x / y;  // 3.5  ← 正确
double r3 = x / 2.0;        // 3.5  ← 正确
```

**两个整数相除，结果还是整数，小数直接丢掉（不是四舍五入）。**

### ★ `=` 和 `==`

```cpp
if (a = 3) { }    // ❌ 赋值，把 a 改成 3，然后判断「3 是否非零」→ 永远真
if (a == 3) { }   // ✅ 比较
```

### ★★★ 表达式不会自己存回去

```cpp
jiage + 10;          // ❌ 算完就扔，jiage 一点没变
jiage = jiage + 10;  // ✅
jiage += 10;         // ✅ 等价
```

**编译器会说 `statement has no effect` —— 翻译过来就是「你算了个东西然后扔了」。**

## 输出 `cout` / 输入 `cin`

```cpp
cout << "文字" << 变量 << endl;   // 可连续写，endl 换行并刷新
cin  >> 变量;                     // 等你敲一个值再回车
```

**箭头方向：`<<` 是往外送（输出），`>>` 是往里收（输入）。**

**输入提示后面建议加 `endl` 或 `": "`，否则所有提示会挤在一行。**

## Windows 上两个经典坑（双击 exe 时）

| 现象 | 原因 | 解决 |
|---|---|---|
| 中文全变成 `璇疯緭鍏` | 程序输出 UTF-8，控制台是 GBK | 开头加 `system("chcp 65001 > nul");`（需 `<cstdlib>`） |
| 算完窗口立刻关掉 | 程序结束窗口就关 | 结尾加 `system("pause");` 或 `_getch()`（需 `<conio.h>`） |

**★ 用 VS Code 的 `Ctrl+Shift+B` 运行不会有这两个问题（终端本来就是 UTF-8，且不会关）。**

## 睡眠函数

| 写法 | 单位 | 需要 |
|---|---|---|
| `Sleep(10000)` | **毫秒**（大写 S） | `<windows.h>`，仅 Windows |
| `this_thread::sleep_for(chrono::seconds(10))` | **秒** | `<thread>` `<chrono>`，跨平台 |

**实测：本机 g++ 4.9.2 支持 `std::thread`，可以用第二种。**
